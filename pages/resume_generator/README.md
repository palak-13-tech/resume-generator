# AI-Powered Resume & ATS Analyzer

## Features
- Upload Resume PDF
- Extract Resume Text
- ATS Score Calculation
- Skill Matching
- Missing Skills Detection
- Dashboard Analytics
- Job Description Analysis

## Technologies Used
- Python
- Streamlit
- PDFPlumber
- Pandas

## How to Run

1. Install requirements

pip install -r requirements.txt

2. Run application

streamlit run app.py
